## 建立假說的準則

**假說**是對母體參數的敘述。檢定時要設立兩個互斥的假說：

- **虛無假說** $H_0$(null hypothesis)：維持現狀、「沒有差異、沒有效果」的說法。
- **對立假說** $H_1$(alternative hypothesis，也記為 $H_a$)：和 $H_0$ 相反，研究者想用資料去證明的說法。

### $H_0$ 與 $H_1$ 的地位不對等

假說檢定的邏輯和法庭審判相同(**無罪推定**)：

| | 法庭 | 假說檢定 |
|---|---|---|
| 預設立場 | 被告**推定無罪** | $H_0$ **先推定為真**，處於**優勢地位** |
| 舉證責任 | 檢察官要提出證據證明有罪 | $H_1$ **需負舉證責任**，處於**劣勢地位**：樣本證據要夠強，才能推翻 $H_0$ |
| 證據標準 | 超越合理懷疑 | 顯著水準 $\alpha$(證據要強到「若 $H_0$ 為真，這種結果很罕見」) |
| 證據足夠 | 判決有罪 | 拒絕 $H_0$，接受 $H_1$ |
| 證據不足 | 判決無罪(不代表證明清白) | 不拒絕 $H_0$(不代表證明 $H_0$ 為真) |
| 冤枉好人 | 型一錯誤：$H_0$ 為真卻拒絕 | 機率 $\alpha$，由研究者事先控制在很小 |
| 縱放壞人 | 型二錯誤：$H_0$ 為假卻不拒絕 | 機率 $\beta$，沒有直接控制 |

因為兩者地位不對等，**放在哪一邊會影響結論**：只有拒絕 $H_0$ 才是「有證據的結論」，不拒絕 $H_0$ 只是「證據不足」。

### 設立假說的準則

1. **想證明的主張放在 $H_1$**：新的說法、新的發現、想要宣稱的效果，要由資料舉證，所以放在 $H_1$；$H_0$ 是它的反面(維持現狀)。
2. **犯錯成本高的錯誤設為型一錯誤**：檢定只直接控制型一錯誤的機率 $\alpha$(例如 5%)，型二錯誤的機率 $\beta$ 可能很大。所以要把「後果比較嚴重的錯誤」安排成型一錯誤，讓它的機率被控制住；也就是把「一旦誤判、代價很高的那個結論」放在 $H_1$，必須有強力證據才接受。
3. **若目前已有樣本證據「傾向支持的一方」，放在 $H_1$**：例如樣本平均已經大於 $\mu_0$，就檢定 $H_1: \mu > \mu_0$，看這個傾向是否強到足以推翻 $H_0$。若反過來把它放在 $H_0$，因為 $H_0$ 處於優勢地位、樣本又沒有反對它，檢定一定不拒絕，得不到任何資訊。(嚴謹的研究最好在看資料之前，就依研究問題或先前的證據決定方向。)
4. **等號放在 $H_0$**：檢定統計量的分配要在 $H_0$ 成立的情況下計算，所以 $H_0$ 必須給出一個明確的參數值(例如 $\mu = \mu_0$)。$H_1$ 則只能是 $\ne$、$>$、$<$。

| 檢定方向 | $H_0$ | $H_1$ | 拒絕域 |
|---|---|---|---|
| 雙尾 | $\mu = \mu_0$ | $\mu \ne \mu_0$ | 兩尾 |
| 右尾 | $\mu \le \mu_0$(或 $\mu = \mu_0$) | $\mu > \mu_0$ | 右尾 |
| 左尾 | $\mu \ge \mu_0$(或 $\mu = \mu_0$) | $\mu < \mu_0$ | 左尾 |

### 例子

| 情境 | $H_0$ | $H_1$ | 型一錯誤(要控制的錯誤) |
|---|---|---|---|
| 新的交易策略宣稱平均報酬為正 | $\mu \le 0$ | $\mu > 0$ | 策略其實沒用卻採用，實際投入資金虧損 |
| 新藥宣稱有效 | 新藥無效 | 新藥有效 | 無效的藥上市，病人延誤治療 |
| 品管：這批零件的不良率是否超過 2% 而要退貨 | $p \le 0.02$ | $p > 0.02$ | 合格的貨被退回，損失供應商與商譽 |
| 基金經理人宣稱績效贏過大盤 | 超額報酬 $\le 0$ | 超額報酬 $> 0$ | 把運氣當成實力，付出高額管理費 |

以第一列為例：某策略回測 60 個月的平均月報酬 $\bar{x} = 0.8\%$(樣本已傾向支持「報酬為正」，放在 $H_1$)。真正要擔心的錯誤是「策略沒用卻以為有用」而投入資金(成本高)，這正好是型一錯誤，被 $\alpha$ 控制住。即使結果是「不拒絕 $H_0$」，也只代表證據不足，不代表證明策略無效。

## 檢定步驟

1. 依上面的準則設立 $H_0$(含等號，維持現狀)與 $H_1$(需要舉證的主張)。
2. 選定顯著水準 $\alpha$，決定檢定統計量與拒絕域(右尾、左尾或雙尾，由 $H_1$ 的方向決定)。
3. 計算檢定統計量或 $p$ 值。
4. 落入拒絕域(或 $p$ 值 $< \alpha$)就拒絕 $H_0$；否則「不拒絕 $H_0$」— 不等於證明 $H_0$ 為真。

## 兩種錯誤與檢定力

|  | $H_0$ 為真 | $H_0$ 為假 |
|---|---|---|
| 拒絕 $H_0$ | 型一錯誤(機率 $\alpha$) | 正確(檢定力 $1 - \beta$) |
| 不拒絕 $H_0$ | 正確($1 - \alpha$) | 型二錯誤(機率 $\beta$) |

$$
\alpha = P(\text{拒絕 } H_0 \mid H_0 \text{ 為真}), \qquad
\beta = P(\text{不拒絕 } H_0 \mid H_0 \text{ 為假}), \qquad
\text{檢定力} = 1 - \beta
$$

- $n$ 固定時 $\alpha$ 與 $\beta$ 此消彼長；要同時降低兩者只能增加樣本數。
- 檢定力隨「真實值與 $\mu_0$ 的距離」、$n$、$\alpha$ 增加而增加，隨 $\sigma$ 增加而減少。畫出 $1 - \beta$ 對真實值的曲線就是檢定力曲線(OC 曲線則是 $\beta$)。

## p 值

$H_0$ 為真時，得到「至少和觀察值一樣極端」的機率。雙尾檢定要乘以 2。$p$ 值**不是** $H_0$ 為真的機率；$p$ 值很小也不代表效果很大。

## 常用檢定統計量

| 檢定 | 條件 | 檢定統計量 |
|---|---|---|
| $\mu$ | $\sigma$ 已知或大樣本 | $Z = \dfrac{\bar{x} - \mu_0}{\sigma/\sqrt{n}}$ |
| $\mu$ | $\sigma$ 未知、常態 | $t = \dfrac{\bar{x} - \mu_0}{s/\sqrt{n}}$，$df = n - 1$ |
| $p$ | 大樣本 | $Z = \dfrac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}$(分母用 $p_0$) |
| $\sigma^2$ | 常態 | $\chi^2 = \dfrac{(n-1)s^2}{\sigma_0^2}$，$df = n - 1$ |
| $\mu_1 - \mu_2$ | 獨立、$\sigma$ 未知相等 | $t = \dfrac{(\bar{x}_1 - \bar{x}_2) - D_0}{s_p\sqrt{1/n_1 + 1/n_2}}$，$df = n_1 + n_2 - 2$ |
| $\mu_D$ | 成對 | $t = \dfrac{\bar{d} - D_0}{s_d/\sqrt{n}}$，$df = n - 1$ |
| $p_1 - p_2$ | $H_0: p_1 = p_2$ | $Z = \dfrac{\hat{p}_1 - \hat{p}_2}{\sqrt{\bar{p}(1-\bar{p})(1/n_1 + 1/n_2)}}$，$\bar{p}$ 為合併比例 |
| $\sigma_1^2 = \sigma_2^2$ | 兩常態 | $F = \dfrac{s_1^2}{s_2^2}$，$df = (n_1 - 1,\ n_2 - 1)$ |

**檢定與區間的關係**：雙尾檢定在 $\alpha$ 下不拒絕 $H_0: \mu = \mu_0$，等價於 $\mu_0$ 落在 $(1 - \alpha)$ 信賴區間內。

> **交易者特別注意 · 多重比較**：同時回測 100 個策略，就算全部無效，在 $\alpha = 0.05$ 下平均也有 5 個「顯著」。挑最好的那個去實戰，常常是被運氣騙了。樣本外驗證很重要。
