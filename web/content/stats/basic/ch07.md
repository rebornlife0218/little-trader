## 估計式與估計值

**估計式**(estimator) $\hat{\theta}$ 是樣本的函數(隨機變數，例如 $\bar{X} = \frac{1}{n}\sum X_i$)；代入實際資料得到的數字叫**估計值**(estimate)。

## 好估計式的性質

- **不偏性**(unbiasedness)：$E(\hat{\theta}) = \theta$。$\bar{X}$、$\hat{p}$、$S^2$(除以 $n-1$)都是不偏估計式；除以 $n$ 的變異數有偏誤 $-\sigma^2/n$。
- **有效性**(efficiency)：都不偏時變異數越小越好。相對效率 $= \operatorname{Var}(\hat{\theta}_2) / \operatorname{Var}(\hat{\theta}_1)$。常態母體下樣本平均數比中位數有效(中位數變異數約為 $\pi/2$ 倍)。
- **一致性**(consistency)：$n \to \infty$ 時 $\hat{\theta} \xrightarrow{P} \theta$。充分條件：偏誤與變異數都趨近 0。
- **充分性**(sufficiency)：$\hat{\theta}$ 已包含樣本中關於 $\theta$ 的所有資訊(費雪–奈曼分解定理)。

$S^2$ 不偏的證明：

$$
E\left[\sum_{i=1}^{n}(X_i - \bar{X})^2\right]
= E\left[\sum_{i=1}^{n} X_i^2 - n\bar{X}^2\right]
= n(\sigma^2 + \mu^2) - n\left(\frac{\sigma^2}{n} + \mu^2\right)
= (n-1)\,\sigma^2
\ \Rightarrow\ E(S^2) = \sigma^2
$$

## 均方誤差

$$
\operatorname{MSE}(\hat{\theta}) = E\left[(\hat{\theta} - \theta)^2\right] = \operatorname{Var}(\hat{\theta}) + \left[\operatorname{Bias}(\hat{\theta})\right]^2
$$

有時接受一點偏誤，換來變異數大幅下降，整體 MSE 反而更小。

**克拉瑪–羅下界**(Cramér–Rao lower bound)：不偏估計式的變異數不會小於

$$
\operatorname{Var}(\hat{\theta}) \ge \frac{1}{n\,I(\theta)}, \qquad I(\theta) = E\left[\left(\frac{\partial}{\partial\theta}\ln f(X;\theta)\right)^2\right]
$$

達到下界者稱為最小變異不偏估計式(MVUE)。

## 動差法

令樣本動差等於母體動差，解出參數：

$$
\frac{1}{n}\sum_{i=1}^{n} X_i = E(X), \qquad \frac{1}{n}\sum_{i=1}^{n} X_i^2 = E(X^2), \qquad \dots
$$

例：$U(0, \theta)$ 的 $E(X) = \theta/2$，令 $\bar{X} = \theta/2 \Rightarrow \hat{\theta} = 2\bar{X}$。

## 最大概似法(MLE)

$$
L(\theta) = \prod_{i=1}^{n} f(x_i; \theta)
\quad\longrightarrow\quad
\text{解 } \frac{d}{d\theta}\ln L(\theta) = 0
$$

| 母體 | MLE |
|---|---|
| 伯努利 $p$ | $\hat{p} = \bar{X}$(樣本比例) |
| 卜瓦松 $\lambda$ | $\hat{\lambda} = \bar{X}$ |
| 指數 $\lambda$ | $\hat{\lambda} = 1 / \bar{X}$ |
| 常態 $\mu, \sigma^2$ | $\hat{\mu} = \bar{X}$，$\hat{\sigma}^2 = \frac{1}{n}\sum(X_i - \bar{X})^2$(有偏誤) |
| $U(0, \theta)$ | $\hat{\theta} = \max(X_i)$(無法微分求解，要直接看 $L(\theta)$) |

MLE 具有**不變性**：$\hat{\theta}$ 是 $\theta$ 的 MLE，則 $g(\hat{\theta})$ 是 $g(\theta)$ 的 MLE。大樣本下 MLE 近似常態、一致且漸近有效。
