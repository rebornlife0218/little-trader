## 信賴區間的意義

若重複抽樣很多次、每次都用同樣方法算區間，約有 $(1 - \alpha)$ 的區間會包含真正的參數。**常見誤解**：「$\mu$ 有 95% 機率在這個區間」— 頻率學派裡 $\mu$ 是固定值，算出來的區間要嘛包含、要嘛不包含。

## 單一母體

| 參數 | 條件 | $(1-\alpha)$ 信賴區間 |
|---|---|---|
| $\mu$ | $\sigma$ 已知(或大樣本) | $\bar{x} \pm z_{\alpha/2}\,\dfrac{\sigma}{\sqrt{n}}$ |
| $\mu$ | $\sigma$ 未知、母體常態 | $\bar{x} \pm t_{\alpha/2,\,n-1}\,\dfrac{s}{\sqrt{n}}$ |
| $p$ | 大樣本 | $\hat{p} \pm z_{\alpha/2}\sqrt{\dfrac{\hat{p}(1-\hat{p})}{n}}$ |
| $\sigma^2$ | 母體常態 | $\left[\dfrac{(n-1)s^2}{\chi^2_{\alpha/2,\,n-1}},\ \dfrac{(n-1)s^2}{\chi^2_{1-\alpha/2,\,n-1}}\right]$ |

常用臨界值：$z_{0.05} = 1.645$、$z_{0.025} = 1.96$、$z_{0.005} = 2.576$。

## 兩母體

| 參數 | 條件 | $(1-\alpha)$ 信賴區間 |
|---|---|---|
| $\mu_1 - \mu_2$ | 獨立，$\sigma$ 已知 | $(\bar{x}_1 - \bar{x}_2) \pm z_{\alpha/2}\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}$ |
| $\mu_1 - \mu_2$ | 獨立，$\sigma$ 未知但相等 | $(\bar{x}_1 - \bar{x}_2) \pm t_{\alpha/2,\,n_1+n_2-2}\; s_p\sqrt{\dfrac{1}{n_1} + \dfrac{1}{n_2}}$ |
| $\mu_1 - \mu_2$ | 獨立，$\sigma$ 未知且不等 | $(\bar{x}_1 - \bar{x}_2) \pm t_{\alpha/2,\,\nu}\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}$ |
| $\mu_D$ | 成對樣本 | $\bar{d} \pm t_{\alpha/2,\,n-1}\,\dfrac{s_d}{\sqrt{n}}$(把每對差值當成一組樣本) |
| $p_1 - p_2$ | 獨立大樣本 | $(\hat{p}_1 - \hat{p}_2) \pm z_{\alpha/2}\sqrt{\dfrac{\hat{p}_1(1-\hat{p}_1)}{n_1} + \dfrac{\hat{p}_2(1-\hat{p}_2)}{n_2}}$ |
| $\sigma_1^2 / \sigma_2^2$ | 兩常態母體 | $\left[\dfrac{s_1^2/s_2^2}{F_{\alpha/2}(n_1-1,\,n_2-1)},\ \dfrac{s_1^2}{s_2^2}\,F_{\alpha/2}(n_2-1,\,n_1-1)\right]$ |

其中合併變異數與 Welch–Satterthwaite 自由度：

$$
s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1 + n_2 - 2}, \qquad
\nu = \frac{\left(\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}\right)^2}{\dfrac{(s_1^2/n_1)^2}{n_1 - 1} + \dfrac{(s_2^2/n_2)^2}{n_2 - 1}}
$$

## 樣本數的決定

誤差界限為 $E$ 時：

$$
\text{估計 } \mu:\ n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2, \qquad
\text{估計 } p:\ n = \frac{z_{\alpha/2}^2\,p(1-p)}{E^2}\ \ (p \text{ 未知時用 } 0.5 \text{ 最保守})
$$

結果一律**無條件進位**。誤差減半，樣本數要變 4 倍。
