## 信賴區間與樞紐量

### 信賴區間的定義

點估計(第 7 章)只給一個數字，看不出誤差有多大；**區間估計**則給一個範圍，並說明這個範圍有多可靠。

設 $L = L(X_1, \ldots, X_n)$、$U = U(X_1, \ldots, X_n)$ 是兩個統計量，$L < U$。因為它們由樣本算出，所以 $[L, U]$ 是一個**隨機區間**。若

$$
P(L < \theta < U) = 1 - \alpha
$$

稱區間 $[L, U]$ 為母數 $\theta$ 之 $(1 - \alpha) \times 100\%$ **信賴區間**(confidence interval, C.I.)。

- $1 - \alpha$ 稱為**信賴水準**(信賴係數)，常用 90%、95%、99%；$\alpha$ 是區間沒有包含 $\theta$ 的機率。
- $[L, U]$ 是**區間估計量**(隨機的公式)；抽樣後代入資料算出的 $[l, u]$(兩個確定的數字)是**區間估計值**。
- 臨界值記號：$z_{\alpha}$、$t_{\alpha,\,\nu}$、$\chi^2_{\alpha,\,\nu}$ 都是**右尾面積為 $\alpha$** 的點，例如 $P(Z > z_{0.025}) = 0.025$、$z_{0.025} = 1.96$(怎麼查見第 6 章「標準常態的尾點(臨界值)」)。

### 樞紐量

**樞紐量**(pivotal quantity)是隨機樣本 $X_1, X_2, \ldots, X_n$ 與待估母數 $\theta$ 的函數組合，而且它的**機率分配不依賴於 $\theta$ 或任何其他未知母體參數**，記作

$$
Q(X_1, X_2, \ldots, X_n;\ \theta)
$$

也就是說，樞紐量**只能含有待估母數 $\theta$ 一個未知母數**，不可含有任何其他的未知母數。例如 $\dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}}$ 在 $\sigma$ 已知時是 $\mu$ 的樞紐量；$\sigma$ 未知時它多了一個未知的 $\sigma$，就不是樞紐量，要改用 $\dfrac{\bar{X} - \mu}{S/\sqrt{n}}$。

**求 $\theta$ 之 $(1 - \alpha) \times 100\%$ 信賴區間的步驟**：

1. 求 $\theta$ 之適當點估計量 $\hat{\theta}$(第 7 章)。
2. 以點估計量 $\hat{\theta}$ 為基礎，求出樞紐量 $Q$ 及其機率分配。
3. 由 $Q$ 的分配找出兩個數 $a$、$b$，使 $P(a < Q < b) = 1 - \alpha$(通常兩邊各留 $\alpha/2$)，再把不等式 $a < Q < b$ 改寫成 $L < \theta < U$。兩個事件相同，所以 $1 - \alpha = P(L < \theta < U)$。
4. $\theta$ 之 $(1 - \alpha) \times 100\%$ 信賴區間為 $[L, U]$。

**例：常態母體、$\sigma$ 已知，求 $\mu$ 的信賴區間**。

1. $\mu$ 的點估計量是 $\bar{X}$。
2. 以 $\bar{X}$ 為基礎，$Z = \dfrac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$：只含一個未知母數 $\mu$，分配和 $\mu$ 無關，是樞紐量(第 6 章「常態母體下的抽樣分配」)。
3. 兩邊各留 $\alpha/2$：

$$
1 - \alpha = P\left(-z_{\alpha/2} < \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} < z_{\alpha/2}\right)
= P\left(\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}} < \mu < \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right)
$$

4. $\mu$ 之 $(1 - \alpha) \times 100\%$ 信賴區間為 $\left[\bar{X} - z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}},\ \bar{X} + z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}\right]$。

本章用到的樞紐量都來自第 6 章「四大抽樣分配」：

| 估計對象 | 樞紐量 | 分配 |
|---|---|---|
| $\mu$(常態，$\sigma$ 已知) | $Z = \dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}}$ | $N(0, 1)$ |
| $\mu$(常態，$\sigma$ 未知) | $T = \dfrac{\bar{X} - \mu}{S/\sqrt{n}}$ | $t(n-1)$ |
| $\sigma^2$(常態，$\mu$ 已知) | $\dfrac{\sum (X_i - \mu)^2}{\sigma^2}$ | $\chi^2(n)$ |
| $\sigma^2$(常態，$\mu$ 未知) | $\dfrac{(n-1)S^2}{\sigma^2}$ | $\chi^2(n-1)$ |
| $p$(大樣本) | $\dfrac{\hat{p} - p}{\sqrt{p(1-p)/n}}$ | 近似 $N(0, 1)$ |
| $\sigma_1^2 / \sigma_2^2$(兩常態) | $\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}$ | $F(n_1 - 1,\ n_2 - 1)$ |

### 信賴區間的意義 [重點]

> **一句話記住**：95% 說的是**建立區間的方法**——重複抽樣很多次，約 95% 的區間會包含 $\mu$；**算出來的那一個區間**不是包含 $\mu$ 就是沒包含，不能說「$\mu$ 有 95% 的機率落在裡面」。

以 95% 信賴區間為例，關鍵是分清楚「抽樣**之前**」和「算出來**之後**」：

- **抽樣之前**：$\bar{X}$ 是隨機變數，$\left[\bar{X} - 1.96\frac{\sigma}{\sqrt{n}},\ \bar{X} + 1.96\frac{\sigma}{\sqrt{n}}\right]$ 是隨機區間，所以可以說「這個隨機區間會包含 $\mu$ 的機率是 0.95」。✔
- **算出來之後**：假設得到 $[50,\ 60]$。$\mu$ 是固定的常數，50、60 也是常數，常數有沒有落在一個範圍內是「是或不是」的問題，沒有機率可言。所以寫 $P(50.2 < \mu < 60) = 0.95$ 是**錯的**，說「$\mu$ 有 95% 的機率落在 $[50, 60]$」也是錯的。✘
- **95% 指的是方法**：想像重複抽樣很多次，每次都用同一個公式算區間，會得到許多不同的區間 $[l_1, u_1], [l_2, u_2], \ldots$。其中約 95% 是包含 $\mu$ 的(做對的)，5% 沒有包含(做錯的)。手上這一個 $[50, 60]$ 只是其中之一，只有對錯的問題，沒有機率的問題。
- **正確的說法**：「我們有 95% 的**信心**，區間 $[50, 60]$ 包含真實的 $\mu$」。這份信心來自建立區間的這套方法，在所有可能算出的區間裡，95% 會做對。

用 R 模擬「95% 指的是方法」：母體 $N(125,\ 15^2)$，每次抽 $n = 100$ 算一個 95% 信賴區間，重複 20 次約有 19 個區間包含 $\mu = 125$；重複越多次，包含的比例越接近 95%。

```r
set.seed(1)
ci <- replicate(20, mean(rnorm(100, mean = 125, sd = 15)) + c(-1, 1) * 1.96 * 15 / sqrt(100))
sum(ci[1, ] < 125 & 125 < ci[2, ])   # 20 個區間中有 18 個包含 μ(每次模擬結果不同)
```

**區間寬度**：雙邊區間的半寬 $z_{\alpha/2}\frac{\sigma}{\sqrt{n}}$ 稱為**誤差界限**(margin of error)。信賴水準越高，區間越寬；樣本數越大，區間越窄。

## 單一母體平均數 μ 的區間估計

依照「母體是否常態」與「$\sigma^2$ 是否已知」分成三種情況。

### Case 1：母體常態分配，σ² 已知

$$
Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0, 1)
\qquad\Longrightarrow\qquad
\bar{X} \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}}
$$

例：某產品重量服從常態、$\sigma = 2$ 公克，抽 25 件得 $\bar{x} = 10.2$。95% 信賴區間為 $10.2 \pm 1.96 \times \frac{2}{\sqrt{25}} = 10.2 \pm 0.784$，即 $[9.416,\ 10.984]$。

例(血壓)：血壓 $X \sim N(\mu,\ 15^2)$，抽 $n = 100$ 人得 $\bar{x} = 123$，求 $\mu$ 的 80% 信賴區間。$\alpha = 0.2$，$z_{0.1} = 1.282$：

$$
123 \pm 1.282 \times \frac{15}{\sqrt{100}} = 123 \pm 1.92 = [121.08,\ 124.92]
$$

我們有 80% 的信心，真正的平均血壓在 121.08 到 124.92 之間。$n$ 越大(成本越高)或信賴水準越低(信心降低)，區間越窄。

```r
qnorm(0.1, lower.tail = FALSE)                       # z_0.1 = 1.2816(右尾面積 0.1 的點)
123 + c(-1, 1) * qnorm(0.9) * 15 / sqrt(100)         # 121.08 124.92
```

### Case 2：母體常態分配，σ² 未知

用 $S$ 代替 $\sigma$，樞紐量從標準常態變成 $t$ 分配(第 6 章「常態母體下的抽樣分配」)：

$$
T = \frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)
\qquad\Longrightarrow\qquad
\bar{X} \pm t_{\alpha/2,\,n-1}\,\frac{S}{\sqrt{n}}
$$

$t$ 分配的尾巴比常態厚，$t_{\alpha/2,\,n-1} > z_{\alpha/2}$，所以區間比 Case 1 寬，反映「$\sigma$ 也要估計」多出來的不確定性；$n$ 越大兩者越接近。

例：某股票 16 天的日報酬，$\bar{x} = 0.12\%$、$s = 1.2\%$，假設日報酬為常態。$t_{0.025,\,15} = 2.131$，95% 信賴區間為 $0.12\% \pm 2.131 \times \frac{1.2\%}{\sqrt{16}} = 0.12\% \pm 0.639\%$，即 $[-0.519\%,\ 0.759\%]$：區間包含 0，無法斷定平均報酬是正的。

例(新生兒身高)：7 位新生兒的身高(英吋)為 18、22、19、17、20、18、15，假設身高為常態，求 $\mu$ 的 90% 信賴區間。$\bar{x} = 18.43$、$s = 2.225$，$t_{0.05,\,6} = 1.943$：

$$
18.43 \pm 1.943 \times \frac{2.225}{\sqrt{7}} = 18.43 \pm 1.63 = [16.79,\ 20.06]
$$

我們有 90% 的信心，真正的平均身高在 16.79 到 20.06 英吋之間。

```r
height <- c(18, 22, 19, 17, 20, 18, 15)
qt(0.05, df = 6, lower.tail = FALSE)         # t_{0.05, 6} = 1.943
t.test(height, conf.level = 0.90)$conf.int   # 16.79 20.06
```

### Case 3：母體非常態分配或未知分配，需大樣本

母體不是常態(或不知道是什麼分配)時，小樣本下 $\bar{X}$ 的分配不確定，沒有現成的樞紐量；**樣本夠大**($n \ge 30$ 為常用的準則)時，由第 6 章「中央極限定理」，$\bar{X}$ 近似常態，用 $S$ 代替 $\sigma$ 也仍然近似常態：

$$
\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \ \dot\sim\ N(0, 1), \qquad \frac{\bar{X} - \mu}{S/\sqrt{n}} \ \dot\sim\ N(0, 1)
\qquad\Longrightarrow\qquad
\bar{X} \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}}\quad(\sigma \text{ 未知時用 } S)
$$

例：100 天的日報酬，$\bar{x} = 0.05\%$、$s = 1.1\%$。95% 信賴區間為 $0.05\% \pm 1.96 \times \frac{1.1\%}{\sqrt{100}} = 0.05\% \pm 0.216\%$，即 $[-0.166\%,\ 0.266\%]$。

例(`Pima.tr`)：不對 BMI 的分配做任何假設，求 Pima 印第安女性平均 BMI 的 90% 信賴區間。$n = 200$、$\bar{x} = 32.31$、$s = 6.13$，標準誤 $6.13/\sqrt{200} = 0.433$：

$$
32.31 \pm 1.645 \times 0.433 = [31.60,\ 33.02]
$$

```r
library(MASS)
x <- Pima.tr$bmi
mean(x) + c(-1, 1) * qnorm(0.95) * sd(x) / sqrt(length(x))   # 31.60 33.02
```

- 這是**近似**的信賴區間，實際的信賴水準只是接近 95%；母體越偏、需要的 $n$ 越大(第 6 章「中央極限定理」的表格)。
- 小樣本又不是常態時，可以改用第 13 章「無母數統計」或第 13 章「自助法(Bootstrap)」。

## 單一母體變異數 σ² 的區間估計

母體必須是**常態分配**(卡方樞紐量對常態假設很敏感，非常態時誤差可能很大)。

### Case 1：μ 已知

$\dfrac{X_i - \mu}{\sigma}$ 是 $n$ 個獨立的標準常態，平方和服從自由度 $n$ 的卡方分配：

$$
\frac{\sum_{i=1}^{n}(X_i - \mu)^2}{\sigma^2} \sim \chi^2(n)
\qquad\Longrightarrow\qquad
\left[\frac{\sum (X_i - \mu)^2}{\chi^2_{\alpha/2,\,n}},\ \frac{\sum (X_i - \mu)^2}{\chi^2_{1-\alpha/2,\,n}}\right]
$$

推導：$P\left(\chi^2_{1-\alpha/2,\,n} < \frac{\sum (X_i - \mu)^2}{\sigma^2} < \chi^2_{\alpha/2,\,n}\right) = 1 - \alpha$，三邊取倒數(不等號反向)再乘上 $\sum (X_i - \mu)^2$。

例：$\mu = 0$ 已知，10 個觀察值的 $\sum x_i^2 = 18$。$\chi^2_{0.025,\,10} = 20.483$、$\chi^2_{0.975,\,10} = 3.247$，$\sigma^2$ 的 95% 信賴區間為 $\left[\frac{18}{20.483},\ \frac{18}{3.247}\right] = [0.879,\ 5.544]$。

### Case 2：μ 未知

用 $\bar{X}$ 代替 $\mu$，少了一個自由度：

$$
\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)
\qquad\Longrightarrow\qquad
\left[\frac{(n-1)S^2}{\chi^2_{\alpha/2,\,n-1}},\ \frac{(n-1)S^2}{\chi^2_{1-\alpha/2,\,n-1}}\right]
$$

- **標準差 $\sigma$ 的信賴區間**：兩端點各開根號即可(開根號是遞增函數，不等式方向不變)。
- 卡方分配右偏，區間**不對稱**：$s^2$ 不在區間正中間，右邊比較長。

例：某股票 20 天日報酬的 $s = 1.5\%$，假設常態。$(n-1)s^2 = 19 \times 2.25 = 42.75$，$\chi^2_{0.025,\,19} = 32.852$、$\chi^2_{0.975,\,19} = 8.907$：

$$
\sigma^2:\ \left[\frac{42.75}{32.852},\ \frac{42.75}{8.907}\right] = [1.301,\ 4.800]\ (\%^2), \qquad
\sigma:\ [1.141\%,\ 2.191\%]
$$

只有 20 天資料時，日波動度的不確定性很大：上界幾乎是下界的兩倍。

例(`Pima.tr`)：200 位女性 BMI 的樣本變異數 $s^2 = 37.6$(母體變異數的點估計)。假設 BMI 為常態，$\sigma^2$ 的 95% 信賴區間為

$$
\left[\frac{199 \times 37.58}{\chi^2_{0.025,\,199}},\ \frac{199 \times 37.58}{\chi^2_{0.975,\,199}}\right] = \left[\frac{7478}{239.96},\ \frac{7478}{161.83}\right] = [31.16,\ 46.21]
$$

```r
library(MASS)
s2 <- var(Pima.tr$bmi)                                  # 37.58
199 * s2 / qchisq(c(0.975, 0.025), df = 199)            # 31.16 46.21
```

## 母體比例 p 的區間估計

$X$ = $n$ 次試驗中的成功次數，$\hat{p} = X/n$。大樣本時由中央極限定理(第 6 章「樣本比例的抽樣分配」)，$\dfrac{\hat{p} - p}{\sqrt{p(1-p)/n}}$ 近似 $N(0, 1)$；標準誤裡的 $p$ 未知，用 $\hat{p}$ 代入：

$$
\hat{p} \pm z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}, \qquad \text{條件：} n\hat{p} \ge 5 \text{ 且 } n(1-\hat{p}) \ge 5
$$

例：策略回測 100 筆交易贏 58 筆，$\hat{p} = 0.58$，標準誤 $\sqrt{0.58 \times 0.42 / 100} \approx 0.0494$。勝率的 95% 信賴區間為 $0.58 \pm 1.96 \times 0.0494 = [0.483,\ 0.677]$：包含 0.5，還不能斷定勝率超過一半。

例(`birthwt`)：189 位母親中有 74 位懷孕期間吸菸，$\hat{p} = 74/189 = 0.392$，求吸菸比例的 95% 信賴區間：

$$
0.392 \pm 1.96\sqrt{\frac{0.392 \times 0.608}{189}} = 0.392 \pm 0.070 = [0.322,\ 0.461]
$$

我們有 95% 的信心，懷孕期間吸菸的母親比例在 32.2% 到 46.1% 之間。

```r
library(MASS)
table(birthwt$smoke)                                    # 0 = 不吸菸 115 人，1 = 吸菸 74 人
p <- 74 / 189
p + c(-1, 1) * 1.96 * sqrt(p * (1 - p) / 189)           # 0.322 0.461(上面的公式)
prop.test(74, 189, correct = FALSE)$conf.int            # 0.325 0.463
```

- `prop.test` 的信賴區間用的是 Wilson 法，和上面的公式略有不同；樣本大時兩者很接近。
- 用 R Commander 的單一比例檢定要注意：它算的是因子的**第一個水準**。`smoke` 的第一個水準是 0(不吸菸)，直接做會得到不吸菸的比例 0.608；要先把水準順序改成 1 在前，或像上面直接輸入次數。

## 兩母體的區間估計

| 參數 | 條件 | $(1-\alpha)$ 信賴區間 |
|---|---|---|
| $\mu_1 - \mu_2$ | Case 1：獨立、兩常態，$\sigma_1^2$、$\sigma_2^2$ 已知 | $(\bar{x}_1 - \bar{x}_2) \pm z_{\alpha/2}\sqrt{\dfrac{\sigma_1^2}{n_1} + \dfrac{\sigma_2^2}{n_2}}$ |
| $\mu_1 - \mu_2$ | Case 2：獨立、兩常態，$\sigma^2$ 未知但相等 | $(\bar{x}_1 - \bar{x}_2) \pm t_{\alpha/2,\,n_1+n_2-2}\; s_p\sqrt{\dfrac{1}{n_1} + \dfrac{1}{n_2}}$ |
| $\mu_1 - \mu_2$ | Case 2：獨立、兩常態，$\sigma^2$ 未知且不等 | $(\bar{x}_1 - \bar{x}_2) \pm t_{\alpha/2,\,\nu}\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}$ |
| $\mu_1 - \mu_2$ | Case 3：獨立、非常態或未知分配，大樣本 | $(\bar{x}_1 - \bar{x}_2) \pm z_{\alpha/2}\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}$ |
| $\mu_D$ | 成對樣本(差值為常態) | $\bar{d} \pm t_{\alpha/2,\,n-1}\,\dfrac{s_d}{\sqrt{n}}$(把每對差值當成一組樣本) |
| $p_1 - p_2$ | 獨立大樣本 | $(\hat{p}_1 - \hat{p}_2) \pm z_{\alpha/2}\sqrt{\dfrac{\hat{p}_1(1-\hat{p}_1)}{n_1} + \dfrac{\hat{p}_2(1-\hat{p}_2)}{n_2}}$ |
| $\sigma_1^2 / \sigma_2^2$ | 獨立、兩常態 | $\left[\dfrac{s_1^2/s_2^2}{F_{\alpha/2}(n_1-1,\,n_2-1)},\ \dfrac{s_1^2}{s_2^2}\,F_{\alpha/2}(n_2-1,\,n_1-1)\right]$ |

其中合併變異數與 Welch–Satterthwaite 自由度(第 6 章「兩獨立母體下的抽樣分配」)：

$$
s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1 + n_2 - 2}, \qquad
\nu = \frac{\left(\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}\right)^2}{\dfrac{(s_1^2/n_1)^2}{n_1 - 1} + \dfrac{(s_2^2/n_2)^2}{n_2 - 1}}
$$

判讀：$\mu_1 - \mu_2$、$p_1 - p_2$ 的區間若**包含 0**，表示兩母體可能沒有差異；$\sigma_1^2/\sigma_2^2$ 的區間若**包含 1**，表示變異數可能相等。

## 單邊信賴區間

有時只關心一邊，例如「勝率**至少**多少」、「波動度**最多**多大」。把 $\alpha$ 全部放在一側：

$$
P(\theta > L) = 1 - \alpha\ \Rightarrow\ [L,\ \infty) \text{ 為信賴下界}, \qquad
P(\theta < U) = 1 - \alpha\ \Rightarrow\ (-\infty,\ U] \text{ 為信賴上界}
$$

作法和雙邊相同，只是臨界值從 $z_{\alpha/2}$ 換成 $z_{\alpha}$(95% 單邊用 1.645，雙邊用 1.96)：

- $\mu$ 的下界(Case 2)：$\bar{X} - t_{\alpha,\,n-1}\,\dfrac{S}{\sqrt{n}}$；上界：$\bar{X} + t_{\alpha,\,n-1}\,\dfrac{S}{\sqrt{n}}$。
- $\sigma^2$ 的上界(Case 2)：$\dfrac{(n-1)S^2}{\chi^2_{1-\alpha,\,n-1}}$，常用在「風險最多多大」。
- 例：上面的策略 100 筆贏 58 筆，勝率的 95% 信賴下界 $= 0.58 - 1.645 \times 0.0494 \approx 0.499$：有 95% 的信心勝率至少 49.9%，仍然沒有超過 50%。
- 例：上面 7 位新生兒的身高，$\mu$ 的 90% 信賴下界 $= 18.43 - t_{0.1,\,6} \times \dfrac{2.225}{\sqrt{7}} = 18.43 - 1.440 \times 0.841 \approx 17.22$：有 90% 的信心平均身高大於 17.22 英吋。雙邊用 $t_{0.05,\,6}$，單邊把 $\alpha = 0.1$ 全部放在一側，改用 $t_{0.1,\,6}$。R：`t.test(height, conf.level = 0.90, alternative = "greater")$conf.int`(17.22 Inf)。
- 單邊信賴區間對應第 9 章的**單尾檢定**：「下界大於 $\theta_0$」等同於在顯著水準 $\alpha$ 下拒絕 $H_0: \theta \le \theta_0$。

## 整理：μ、σ、p 的信賴區間

| 參數 | Case | 樞紐量 | 雙邊 $(1-\alpha)$ 信賴區間 | 單邊下界 / 上界 |
|---|---|---|---|---|
| $\mu$ | 常態，$\sigma^2$ 已知 | $Z = \dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$ | $\bar{X} \pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$ | $\bar{X} \mp z_{\alpha}\dfrac{\sigma}{\sqrt{n}}$ |
| $\mu$ | 常態，$\sigma^2$ 未知 | $T = \dfrac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$ | $\bar{X} \pm t_{\alpha/2,\,n-1}\dfrac{S}{\sqrt{n}}$ | $\bar{X} \mp t_{\alpha,\,n-1}\dfrac{S}{\sqrt{n}}$ |
| $\mu$ | 非常態或未知分配，大樣本 | $\dfrac{\bar{X} - \mu}{S/\sqrt{n}} \ \dot\sim\ N(0,1)$ | $\bar{X} \pm z_{\alpha/2}\dfrac{S}{\sqrt{n}}$($\sigma$ 已知用 $\sigma$) | $\bar{X} \mp z_{\alpha}\dfrac{S}{\sqrt{n}}$ |
| $\sigma^2$ | 常態，$\mu$ 已知 | $\dfrac{\sum (X_i - \mu)^2}{\sigma^2} \sim \chi^2(n)$ | $\left[\dfrac{\sum (X_i - \mu)^2}{\chi^2_{\alpha/2,\,n}},\ \dfrac{\sum (X_i - \mu)^2}{\chi^2_{1-\alpha/2,\,n}}\right]$ | 下界 $\dfrac{\sum (X_i - \mu)^2}{\chi^2_{\alpha,\,n}}$、上界 $\dfrac{\sum (X_i - \mu)^2}{\chi^2_{1-\alpha,\,n}}$ |
| $\sigma^2$ | 常態，$\mu$ 未知 | $\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$ | $\left[\dfrac{(n-1)S^2}{\chi^2_{\alpha/2,\,n-1}},\ \dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2,\,n-1}}\right]$ | 下界 $\dfrac{(n-1)S^2}{\chi^2_{\alpha,\,n-1}}$、上界 $\dfrac{(n-1)S^2}{\chi^2_{1-\alpha,\,n-1}}$ |
| $\sigma$ | 同 $\sigma^2$ 的兩種 Case | 同上 | $\sigma^2$ 的區間兩端點開根號 | 同左，開根號 |
| $p$ | 大樣本 | $\dfrac{\hat{p} - p}{\sqrt{p(1-p)/n}} \ \dot\sim\ N(0,1)$ | $\hat{p} \pm z_{\alpha/2}\sqrt{\dfrac{\hat{p}(1-\hat{p})}{n}}$ | $\hat{p} \mp z_{\alpha}\sqrt{\dfrac{\hat{p}(1-\hat{p})}{n}}$ |

單邊欄的 $\mp$：取「$-$」是信賴下界、取「$+$」是信賴上界。常用臨界值：$z_{0.05} = 1.645$、$z_{0.025} = 1.96$、$z_{0.005} = 2.576$。

## 樣本數問題

誤差界限為 $E$ 時：

$$
\text{估計 } \mu:\ n = \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2, \qquad
\text{估計 } p:\ n = \frac{z_{\alpha/2}^2\,p(1-p)}{E^2}\ \ (p \text{ 未知時用 } 0.5 \text{ 最保守})
$$

結果一律**無條件進位**。誤差減半，樣本數要變 4 倍。例：想把勝率估計到 $\pm 5\%$(95% 信賴水準)，至少需要 $\frac{1.96^2 \times 0.25}{0.05^2} = 384.2$，即 385 筆交易。
