## 迴歸分析的基本觀念

### 相關與迴歸

兩個數值變數之間的關係，有兩種問法：

- **相關分析**：兩個變數一起變動的方向與強度有多大？兩個變數地位對等。
- **迴歸分析**：用自變數 $x$ **解釋或預測**應變數 $Y$ 的平均變化，要找出一條具體的方程式。

衡量線性關係強度的是樣本**相關係數**：

$$
r = \frac{S_{xy}}{\sqrt{S_{xx}\,S_{yy}}}, \qquad
S_{xy} = \sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y}), \quad
S_{xx} = \sum_{i=1}^{n}(x_i - \bar{x})^2, \quad
S_{yy} = \sum_{i=1}^{n}(y_i - \bar{y})^2
$$

- $-1 \le r \le 1$；$r$ 只衡量**線性**關係($r = 0$ 仍可能有曲線關係)，而且對離群值敏感。
- **相關不等於因果**：冰淇淋銷量和溺水人數正相關，真正原因是天氣熱。

### 名詞

| 名詞 | 意思 | 例子 |
|---|---|---|
| 應變數(反應變數)$Y$ | 要解釋、預測的變數 | 個股報酬 |
| 自變數(解釋變數)$x$ | 用來解釋 $Y$ 的變數 | 大盤報酬 |
| 迴歸係數 $\beta_0, \beta_1$ | 母體迴歸線的截距與斜率(母數) | 個股的 $\alpha$、$\beta$ |
| 誤差 $\varepsilon_i$ | $Y_i$ 與母體迴歸線的差距，看不到 | 公司特有的消息 |
| 配適值 $\hat{y}_i$ | 樣本迴歸線上的值 $b_0 + b_1 x_i$ | |
| 殘差 $e_i$ | $y_i - \hat{y}_i$，誤差的估計值 | |

### 簡單線性迴歸模型與基本假設

用一個自變數 $x$ 解釋應變數 $Y$ 的平均變化：

$$
Y_i = \beta_0 + \beta_1 x_i + \varepsilon_i, \qquad i = 1, 2, \ldots, n
$$

$\beta_0$(截距)、$\beta_1$(斜率)、$\sigma^2$ 是未知的母體參數；$\varepsilon_i$ 是誤差項，代表 $x$ 以外所有影響 $Y$ 的因素。模型有六個假設：

1. **線性關係**：變數 $Y_i$ 與 $x_i$ 具有模型設定的線性關係 $Y_i = \beta_0 + \beta_1 x_i + \varepsilon_i$(對參數為線性；$x$ 可以先取對數等轉換)。
2. **$x_i$ 為非隨機**：$x_i$ 是固定、已知的數值(例如實驗者設定的水準)，所以寫成小寫；只有 $\varepsilon_i$ 與 $Y_i$ 是隨機變數。$x_i$ 也不能全部相同($S_{xx} > 0$)，否則無法估計斜率。
3. **誤差的期望值為 0**：$E(\varepsilon_i) = 0$，所以 $E(Y_i) = \beta_0 + \beta_1 x_i$，迴歸線描述的是 $Y$ 的**條件平均數**。
4. **同質變異數**：$\operatorname{Var}(\varepsilon_i) = \sigma^2$，不論 $x_i$ 多少，誤差的變異數都相同；違反時稱為**異質變異**。
5. **序列獨立**：$\operatorname{Cov}(\varepsilon_i, \varepsilon_j) = 0$，$i \ne j$，不同觀察值的誤差沒有相關；時間序列資料常違反(**自我相關**)。
6. **常態性**：$\varepsilon_i \sim N(0, \sigma^2)$。

在六個假設下，$Y_1, \ldots, Y_n$ 互相獨立，且

$$
Y_i \sim N\left(\beta_0 + \beta_1 x_i,\ \sigma^2\right)
$$

也就是每個 $x$ 底下，$Y$ 都是以迴歸線上的點為中心、變異數相同的常態分配。假設 1～5 足以推出最小平方估計式的好性質(高斯–馬可夫定理)；假設 6 用來推導 $t$、$F$ 等精確的抽樣分配，大樣本時可以放寬。

## 簡單線性迴歸的點估計

### 最小平方法(OLS)

選擇 $b_0$、$b_1$ 使殘差平方和最小：

$$
\min_{b_0,\ b_1} \sum_{i=1}^{n}\left(y_i - b_0 - b_1 x_i\right)^2
$$

對 $b_0$、$b_1$ 偏微分令其為 0，得到**正規方程式** $\sum e_i = 0$、$\sum x_i e_i = 0$($e_i = y_i - b_0 - b_1 x_i$)，解得

$$
b_1 = \frac{S_{xy}}{S_{xx}} = r\,\frac{s_y}{s_x}, \qquad b_0 = \bar{y} - b_1\bar{x}, \qquad \hat{y}_i = b_0 + b_1 x_i
$$

- 迴歸線一定通過 $(\bar{x}, \bar{y})$。
- 斜率 $b_1$：$x$ 每增加 1 單位，$Y$ 的**平均**增加 $b_1$ 單位。不要在資料範圍以外**外插**預測。
- $\sigma^2$ 的不偏估計式(兩個係數已經用掉 2 個自由度)：

$$
s^2 = MSE = \frac{SSE}{n - 2} = \frac{\sum (y_i - \hat{y}_i)^2}{n - 2}, \qquad E(s^2) = \sigma^2
$$

### 最大概似估計(MLE)

在常態性假設下，$Y_i \sim N(\beta_0 + \beta_1 x_i, \sigma^2)$ 互相獨立，概似函數的對數為

$$
\ln L(\beta_0, \beta_1, \sigma^2) = -\frac{n}{2}\ln(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^{n}\left(y_i - \beta_0 - \beta_1 x_i\right)^2
$$

- 對 $\beta_0$、$\beta_1$ 極大化 $\ln L$，等同極小化 $\sum (y_i - \beta_0 - \beta_1 x_i)^2$，所以**係數的 MLE 和最小平方估計式完全相同**：$\hat{\beta}_1 = b_1$、$\hat{\beta}_0 = b_0$。
- $\sigma^2$ 的 MLE 是 $\hat{\sigma}^2_{MLE} = \dfrac{SSE}{n}$，分母是 $n$ 而不是 $n - 2$，所以是**偏誤**的(低估)，但 $n$ 大時兩者差不多(一致)。

### 高斯–馬可夫定理

在假設 1～5 下(**不需要常態性**)，最小平方估計式 $b_0$、$b_1$ 是**最佳線性不偏估計式**(Best Linear Unbiased Estimator，**BLUE**)：

- **線性**：$b_1$ 是 $Y_i$ 的線性組合，$b_1 = \sum k_i Y_i$，權數 $k_i = \dfrac{x_i - \bar{x}}{S_{xx}}$(因為 $x_i$ 非隨機，$k_i$ 是常數)。$b_0$ 也是。
- **不偏**：$E(b_1) = \beta_1$、$E(b_0) = \beta_0$。
- **最佳**：在所有線性不偏估計式中，變異數最小。

定理的意義：只要誤差平均為 0、同質變異數、序列獨立，就沒有其他「線性且不偏」的方法比最小平方法更精確。若再加上常態性，最小平方估計式更是**所有**不偏估計式中變異數最小的(不限線性)。反過來說，異質變異或自我相關時，最小平方估計式仍然不偏，但不再是「最佳」，而且通常的標準誤公式會算錯。

## 抽樣分配與樞紐量

### 迴歸係數與平均反應

因為 $b_0$、$b_1$、$\hat{Y}_0$ 都是常態隨機變數 $Y_i$ 的線性組合，在六個假設下都是常態：

$$
b_1 \sim N\left(\beta_1,\ \frac{\sigma^2}{S_{xx}}\right), \qquad
b_0 \sim N\left(\beta_0,\ \sigma^2\left[\frac{1}{n} + \frac{\bar{x}^2}{S_{xx}}\right]\right), \qquad
\operatorname{Cov}(b_0, b_1) = -\frac{\bar{x}\,\sigma^2}{S_{xx}}
$$

在 $x = x_0$ 的平均反應 $\hat{Y}_0 = b_0 + b_1 x_0$ 估計 $E(Y_0) = \beta_0 + \beta_1 x_0$：

$$
\hat{Y}_0 \sim N\left(\beta_0 + \beta_1 x_0,\ \sigma^2\left[\frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}\right]\right)
$$

- $S_{xx}$ 越大($x$ 越分散)、$n$ 越大，$b_1$ 越精確；$x_0$ 離 $\bar{x}$ 越遠，平均反應越不精確。
- $\bar{x} > 0$ 時 $b_0$、$b_1$ 負相關：斜率估得太大，截距就會估得太小(迴歸線繞著 $(\bar{x}, \bar{y})$ 轉)。

### 誤差平方和

$$
\frac{SSE}{\sigma^2} = \frac{(n-2)s^2}{\sigma^2} \sim \chi^2(n - 2), \qquad SSE \text{ 與 } b_0, b_1 \text{ 獨立}
$$

### 樞紐量

$\sigma^2$ 未知，用 $s^2 = MSE$ 代替，標準化後就從常態變成 $t(n-2)$(和第 6 章「四大抽樣分配」中 $\sigma^2$ 未知時的推導相同)。和第 8 章「信賴區間與樞紐量」一樣，以下樞紐量的分配都不含未知母數，是區間估計與檢定的共同基礎：

| 母數 | 點估計 | 標準誤 | 樞紐量 | 分配 |
|---|---|---|---|---|
| $\beta_1$ | $b_1$ | $s_{b_1} = \dfrac{s}{\sqrt{S_{xx}}}$ | $\dfrac{b_1 - \beta_1}{s_{b_1}}$ | $t(n-2)$ |
| $\beta_0$ | $b_0$ | $s_{b_0} = s\sqrt{\dfrac{1}{n} + \dfrac{\bar{x}^2}{S_{xx}}}$ | $\dfrac{b_0 - \beta_0}{s_{b_0}}$ | $t(n-2)$ |
| $E(Y_0)$ | $\hat{y}_0$ | $s_{\hat{y}_0} = s\sqrt{\dfrac{1}{n} + \dfrac{(x_0 - \bar{x})^2}{S_{xx}}}$ | $\dfrac{\hat{Y}_0 - E(Y_0)}{s_{\hat{y}_0}}$ | $t(n-2)$ |
| $Y_0$(個別值) | $\hat{y}_0$ | $s_{pred} = s\sqrt{1 + \dfrac{1}{n} + \dfrac{(x_0 - \bar{x})^2}{S_{xx}}}$ | $\dfrac{Y_0 - \hat{Y}_0}{s_{pred}}$ | $t(n-2)$ |
| $\sigma^2$ | $s^2 = MSE$ | | $\dfrac{(n-2)s^2}{\sigma^2}$ | $\chi^2(n-2)$ |

## 變異分解與判定係數

### 變異分解

$$
\underbrace{\sum(y_i - \bar{y})^2}_{SST\ (df = n - 1)} = \underbrace{\sum(\hat{y}_i - \bar{y})^2}_{SSR\ (df = 1)} + \underbrace{\sum(y_i - \hat{y}_i)^2}_{SSE\ (df = n - 2)}
$$

- $SST$：$Y$ 的總變異；$SSR$：迴歸線解釋的變異；$SSE$：解釋不了的變異。
- 計算時可用 $SST = S_{yy}$、$SSR = b_1 S_{xy} = b_1^2 S_{xx}$、$SSE = SST - SSR$。

### 判定係數

$$
R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}
$$

- **判定係數** $R^2$：$Y$ 的變異中，能被 $x$ 的線性關係解釋的比例，$0 \le R^2 \le 1$。簡單迴歸時 $R^2 = r^2$。
- $R^2$ 高不代表模型正確(可能是曲線關係、離群值或兩個都有趨勢的時間序列)；$R^2$ 低也不代表斜率不顯著(資料多時，很小的關係也會顯著)。

### 殘差性質

殘差 $e_i = y_i - \hat{y}_i$ 是誤差 $\varepsilon_i$ 的估計值，由正規方程式可得：

- $\sum e_i = 0$：殘差加總為 0(模型有截距時)，所以 $\sum \hat{y}_i = \sum y_i$，$\bar{\hat{y}} = \bar{y}$。
- $\sum x_i e_i = 0$：殘差和自變數無關。
- $\sum \hat{y}_i e_i = 0$：殘差和配適值無關，這是 $SST = SSR + SSE$ 成立的原因。
- 殘差有上面兩條限制式，只有 $n - 2$ 個可以自由變動，所以 $SSE$ 的自由度是 $n - 2$。
- 殘差**不完全獨立、變異數也不相等**：$\operatorname{Var}(e_i) = \sigma^2(1 - h_{ii})$，其中**槓桿值** $h_{ii} = \dfrac{1}{n} + \dfrac{(x_i - \bar{x})^2}{S_{xx}}$。$x_i$ 離 $\bar{x}$ 越遠，槓桿越大，迴歸線會被它「拉過去」，殘差反而變小。所以檢查離群值時常用**標準化殘差** $\dfrac{e_i}{s\sqrt{1 - h_{ii}}}$。

## 簡單線性迴歸的區間估計

由上面的樞紐量，依第 8 章「信賴區間與樞紐量」的步驟，得到各母數的 $(1 - \alpha) \times 100\%$ 區間：

**Case 1：斜率 $\beta_1$**

$$
b_1 \pm t_{\alpha/2,\ n-2}\ \frac{s}{\sqrt{S_{xx}}}
$$

**Case 2：截距 $\beta_0$**

$$
b_0 \pm t_{\alpha/2,\ n-2}\ s\sqrt{\frac{1}{n} + \frac{\bar{x}^2}{S_{xx}}}
$$

截距常常沒有實際意義($x = 0$ 可能在資料範圍外)。

**Case 3：誤差變異數 $\sigma^2$**(和第 8 章「單一母體變異數 σ² 的區間估計」Case 2 相同，自由度換成 $n - 2$)

$$
\left[\frac{SSE}{\chi^2_{\alpha/2,\ n-2}},\ \frac{SSE}{\chi^2_{1-\alpha/2,\ n-2}}\right]
$$

**Case 4：平均反應 $E(Y_0)$ 的信賴區間與個別值 $Y_0$ 的預測區間**($x = x_0$)

$$
\text{平均反應 } E(Y_0):\ \hat{y}_0 \pm t_{\alpha/2,\ n-2}\ s\sqrt{\frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}}
\qquad
\text{個別值 } Y_0:\ \hat{y}_0 \pm t_{\alpha/2,\ n-2}\ s\sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{x})^2}{S_{xx}}}
$$

- 平均反應估的是**母數** $E(Y_0)$，叫信賴區間；個別值 $Y_0$ 是**隨機變數**，叫預測區間。
- 預測個別值還要加上新觀察值本身的誤差 $\varepsilon_0$(根號內多 1)，所以預測區間比信賴區間寬；$n$ 再大，預測區間的寬度也不會小於 $\pm t\,s$。
- $x_0$ 離 $\bar{x}$ 越遠兩者都越寬，這也是不要外插的原因之一。

## 簡單線性迴歸的檢定

### 斜率的 t 檢定

最常用的問題：$x$ 和 $Y$ 有沒有線性關係？

$$
H_0: \beta_1 = \beta_{10}, \qquad t = \frac{b_1 - \beta_{10}}{s_{b_1}} \ \overset{H_0}{\sim}\ t(n - 2)
$$

| 對立假說 | 拒絕域 |
|---|---|
| $H_1: \beta_1 \ne \beta_{10}$ | $\lvert t \rvert > t_{\alpha/2,\ n-2}$ |
| $H_1: \beta_1 > \beta_{10}$ | $t > t_{\alpha,\ n-2}$ |
| $H_1: \beta_1 < \beta_{10}$ | $t < -t_{\alpha,\ n-2}$ |

- 最常見的是 $\beta_{10} = 0$(斜率是否顯著)；也可以檢定個股 $\beta$ 是否等於 1($\beta_{10} = 1$)。
- 截距的檢定同理，分母換成 $s_{b_0}$。

### 迴歸的 F 檢定

和第 10 章「F 檢定統計量的由來」相同，比較兩個均方的期望值：

$$
E(MSE) = \sigma^2, \qquad E(MSR) = \sigma^2 + \beta_1^2 S_{xx}, \qquad MSR = \frac{SSR}{1},\ MSE = \frac{SSE}{n-2}
$$

當 $H_0: \beta_1 = 0$ 成立時，$\dfrac{SSR}{\sigma^2} \sim \chi^2(1)$ 且與 $SSE$ 獨立，所以

$$
F = \frac{MSR}{MSE} = \frac{\dfrac{SSR}{\sigma^2}\Big/1}{\dfrac{SSE}{\sigma^2}\Big/(n-2)} \ \overset{H_0}{\sim}\ F(1,\ n - 2)
$$

$\beta_1 \ne 0$ 時 $E(MSR) > E(MSE)$，$F$ 會偏大，所以**拒絕域只在右尾**：$F > F_{\alpha}(1,\ n - 2)$。整理成變異數分析表：

| 變異來源 | 平方和 | 自由度 | 均方 | $F$ |
|---|---|---|---|---|
| 迴歸 | $SSR$ | 1 | $MSR = SSR / 1$ | $MSR / MSE$ |
| 誤差 | $SSE$ | $n - 2$ | $MSE = SSE / (n - 2)$ | |
| 總和 | $SST$ | $n - 1$ | | |

### 相關係數的檢定

$$
H_0: \rho = 0, \qquad t = \frac{r\sqrt{n-2}}{\sqrt{1 - r^2}} \ \overset{H_0}{\sim}\ t(n - 2)
$$

**三個檢定等價**：簡單迴歸中，斜率的 $t$ 檢定($H_0: \beta_1 = 0$)、變異數分析的 $F$ 檢定($F = t^2$)、相關係數的檢定($H_0: \rho = 0$)，算出的 $t$ 值相同，結論完全相同。

## 例子

某檔股票與大盤 5 個月的月報酬(%)，以大盤報酬 $x$ 解釋個股報酬 $y$：

| 月份 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 大盤 $x$ | 1 | 2 | 3 | 4 | 5 |
| 個股 $y$ | 2 | 3 | 5 | 4 | 6 |

**點估計**：$\bar{x} = 3$、$\bar{y} = 4$，$S_{xx} = 10$、$S_{xy} = 9$、$S_{yy} = 10$。

$$
b_1 = \frac{9}{10} = 0.9, \qquad b_0 = 4 - 0.9 \times 3 = 1.3, \qquad \hat{y} = 1.3 + 0.9x
$$

| $x_i$ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| $\hat{y}_i$ | 2.2 | 3.1 | 4.0 | 4.9 | 5.8 |
| $e_i$ | $-0.2$ | $-0.1$ | $1.0$ | $-0.9$ | $0.2$ |

殘差加總為 0。$SSE = 0.04 + 0.01 + 1 + 0.81 + 0.04 = 1.9$，$s^2 = 1.9 / 3 = 0.633$，$s = 0.796$。

**變異分解**：$SST = 10$、$SSR = b_1 S_{xy} = 8.1$、$SSE = 1.9$，$R^2 = 0.81$，$r = \sqrt{0.81} = 0.9$(斜率為正)。

**檢定 $H_0: \beta_1 = 0$**($\alpha = 0.05$)：$s_{b_1} = 0.796 / \sqrt{10} = 0.252$，

$$
t = \frac{0.9}{0.252} = 3.58 > t_{0.025,\ 3} = 3.182 \quad\Rightarrow\quad \text{拒絕 } H_0,\ p \approx 0.037
$$

| 變異來源 | 平方和 | 自由度 | 均方 | $F$ |
|---|---|---|---|---|
| 迴歸 | 8.1 | 1 | 8.1 | 12.79 |
| 誤差 | 1.9 | 3 | 0.633 | |
| 總和 | 10 | 4 | | |

$F = 12.79 = 3.58^2 > F_{0.05}(1, 3) = 10.13$，結論相同；相關係數的檢定 $t = \dfrac{0.9\sqrt{3}}{\sqrt{0.19}} = 3.58$ 也一樣。

**檢定 $H_0: \beta_1 = 1$**(個股是否和大盤同步)：$t = \dfrac{0.9 - 1}{0.252} = -0.40$，$\lvert t \rvert < 3.182$，不拒絕 $H_0$。

**區間估計**(95%)：

| 母數 | 區間 | 結果 |
|---|---|---|
| $\beta_1$ | $0.9 \pm 3.182 \times 0.252$ | $[0.10,\ 1.70]$ |
| $\beta_0$ | $1.3 \pm 3.182 \times 0.835$ | $[-1.36,\ 3.96]$ |
| $\sigma^2$ | $\left[\dfrac{1.9}{9.348},\ \dfrac{1.9}{0.216}\right]$ | $[0.20,\ 8.80]$ |
| $E(Y_0)$，$x_0 = 4$ | $4.9 \pm 3.182 \times 0.796\sqrt{0.2 + 0.1}$ | $[3.51,\ 6.29]$ |
| $Y_0$，$x_0 = 4$ | $4.9 \pm 3.182 \times 0.796\sqrt{1 + 0.2 + 0.1}$ | $[2.01,\ 7.79]$ |

$\beta_1$ 的區間不含 0(和拒絕 $\beta_1 = 0$ 一致)，但含 1(和不拒絕 $\beta_1 = 1$ 一致)。只有 5 筆資料，區間都很寬，預測區間又比平均反應的信賴區間寬得多。

## 殘差分析

殘差分析是檢查模型假設的主要方法：

- 殘差對 $x$ 或 $\hat{y}$ 的圖應該隨機散布：呈曲線代表違反假設 1(不是線性)，呈喇叭形代表違反假設 4(**異質變異**)。
- 殘差依時間順序畫圖或用 Durbin–Watson 檢定，檢查假設 5(時間序列資料的**自我相關**)。
- 常態機率圖(Q-Q 圖)檢查假設 6(常態性)。
- 標準化殘差 $|e| > 2$ 或 $3$ 為離群值；高槓桿點與影響點(Cook's D)會大幅改變迴歸線。

## 複迴歸

### 模型與假設

$$
Y_i = \beta_0 + \beta_1 x_{i1} + \cdots + \beta_k x_{ik} + \varepsilon_i, \qquad \varepsilon_i \overset{iid}{\sim} N(0, \sigma^2)
$$

假設和簡單迴歸相同，另外要求自變數之間沒有完全的線性關係。係數仍用最小平方法估計(矩陣寫法 $\mathbf{b} = (X^{\top}X)^{-1}X^{\top}\mathbf{y}$)，$\sigma^2$ 的不偏估計為 $s^2 = MSE = \dfrac{SSE}{n - k - 1}$($k + 1$ 個係數用掉 $k + 1$ 個自由度)。

- $b_i$：**其他變數固定**時，$x_i$ 增加 1 單位 $Y$ 的平均變化。
- 類別變數用虛擬變數($k$ 類用 $k - 1$ 個)。

### 變異分解與 ANOVA 表

| 變異來源 | 平方和 | 自由度 | 均方 | $F$ |
|---|---|---|---|---|
| 迴歸 | $SSR$ | $k$ | $MSR = SSR / k$ | $MSR / MSE$ |
| 誤差 | $SSE$ | $n - k - 1$ | $MSE = SSE / (n - k - 1)$ | |
| 總和 | $SST$ | $n - 1$ | | |

$$
R^2 = \frac{SSR}{SST}, \qquad R_a^2 = 1 - (1 - R^2)\,\frac{n - 1}{n - k - 1}
$$

加入變數 $R^2$ 一定不會下降，所以比較模型要用**調整後** $R_a^2$，它會對多用的自由度做懲罰。

### 檢定

- **整體 $F$ 檢定**：$H_0: \beta_1 = \cdots = \beta_k = 0$(所有自變數都沒用)，$F = \dfrac{MSR}{MSE} \overset{H_0}{\sim} F(k,\ n - k - 1)$，右尾。
- **個別 $t$ 檢定**：$H_0: \beta_i = 0$(其他變數已在模型中時，$x_i$ 是否還有額外的解釋力)，$t = \dfrac{b_i}{s_{b_i}} \overset{H_0}{\sim} t(n - k - 1)$；$\beta_i$ 的信賴區間為 $b_i \pm t_{\alpha/2,\ n-k-1}\ s_{b_i}$。
- 整體顯著、個別都不顯著，常是**多重共線性**：自變數彼此高度相關，係數的標準誤變大、正負號可能怪異($VIF > 10$ 要注意)。

## 整理：迴歸的區間估計與檢定

| 母數 | 樞紐量 / 檢定統計量 | 分配 | 信賴區間 | 拒絕域(雙尾) |
|---|---|---|---|---|
| $\beta_1$ | $\dfrac{b_1 - \beta_1}{s / \sqrt{S_{xx}}}$ | $t(n-2)$ | $b_1 \pm t_{\alpha/2,\ n-2}\,\dfrac{s}{\sqrt{S_{xx}}}$ | $\lvert t \rvert > t_{\alpha/2,\ n-2}$ |
| $\beta_0$ | $\dfrac{b_0 - \beta_0}{s\sqrt{\frac{1}{n} + \frac{\bar{x}^2}{S_{xx}}}}$ | $t(n-2)$ | $b_0 \pm t_{\alpha/2,\ n-2}\, s\sqrt{\dfrac{1}{n} + \dfrac{\bar{x}^2}{S_{xx}}}$ | $\lvert t \rvert > t_{\alpha/2,\ n-2}$ |
| $\sigma^2$ | $\dfrac{SSE}{\sigma^2}$ | $\chi^2(n-2)$ | $\left[\dfrac{SSE}{\chi^2_{\alpha/2,\ n-2}},\ \dfrac{SSE}{\chi^2_{1-\alpha/2,\ n-2}}\right]$ | $\chi^2 > \chi^2_{\alpha/2}$ 或 $< \chi^2_{1-\alpha/2}$ |
| $E(Y_0)$ | $\dfrac{\hat{Y}_0 - E(Y_0)}{s_{\hat{y}_0}}$ | $t(n-2)$ | $\hat{y}_0 \pm t_{\alpha/2,\ n-2}\, s\sqrt{\dfrac{1}{n} + \dfrac{(x_0 - \bar{x})^2}{S_{xx}}}$ | |
| $Y_0$(預測) | $\dfrac{Y_0 - \hat{Y}_0}{s_{pred}}$ | $t(n-2)$ | $\hat{y}_0 \pm t_{\alpha/2,\ n-2}\, s\sqrt{1 + \dfrac{1}{n} + \dfrac{(x_0 - \bar{x})^2}{S_{xx}}}$ | |
| $\beta_1 = 0$(F) | $\dfrac{MSR}{MSE}$ | $F(1,\ n-2)$ | | $F > F_{\alpha}(1,\ n-2)$ |
| $\rho = 0$ | $\dfrac{r\sqrt{n-2}}{\sqrt{1 - r^2}}$ | $t(n-2)$ | | $\lvert t \rvert > t_{\alpha/2,\ n-2}$ |
| 複迴歸 $\beta_i$ | $\dfrac{b_i - \beta_i}{s_{b_i}}$ | $t(n-k-1)$ | $b_i \pm t_{\alpha/2,\ n-k-1}\, s_{b_i}$ | $\lvert t \rvert > t_{\alpha/2,\ n-k-1}$ |
| 複迴歸整體 | $\dfrac{MSR}{MSE}$ | $F(k,\ n-k-1)$ | | $F > F_{\alpha}(k,\ n-k-1)$ |

共同點：$t$ 的自由度都是 **$n$ 減去估計的係數個數**(簡單迴歸 $n - 2$、複迴歸 $n - k - 1$)。

> **金融用語 · Beta**：個股報酬對大盤報酬做迴歸，斜率就是 $\beta$。$\beta = 1.2$ 代表大盤漲 1%，這檔股票平均漲 1.2%；$R^2$ 代表系統性風險占總風險的比例。
