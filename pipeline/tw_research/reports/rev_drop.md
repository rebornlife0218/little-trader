# 營收衰退開低

> **一句話結論**：營收衰退公告後隔天開盤大跌的股票，開盤買進、當天收盤賣，總報酬只有 {日內｜全部_ret}，遠輸 0050 的 {b_ret}；隔天才賣（T+1）是虧損的，而且獲利只出現在幾乎買不到量的冷門股。

回測期間：{start} ～ {end}｜本金 100 萬元，所有報酬都已扣除手續費、證交稅與滑價

## 一、研究目的

營收衰退公告後，隔天開盤大跌的股票可能殺過頭。這份研究要回答：

1. 在這些股票開盤時買進，賺開盤後的反彈，扣掉成本後能不能獲利？
2. 當天收盤賣（日內）和隔天開盤賣（T+1），哪一種比較好？
3. 能不能贏過買進持有 0050？獲利集中在哪些股票？

## 二、資料處理

| 項目 | 處理方式 |
|---|---|
| 事件日 T0 | 月營收公告日（通常收盤後公告）。只用月底後 15 天內的公告 |
| 營收條件 | 單月合併營收年增率 < -10%（合併數字缺值時用單月營收） |
| 開低條件 | 公告後第一個交易日 T1 開盤價相對 T0 收盤跳空 ≤ -5%（以還原股價計算，除權息不會被誤判成開低） |
| 範圍 | 上市櫃普通股（排除 ETF、存託憑證 91xx，含已下市櫃公司）；另測事前 20 日均額 ≥ 1 千萬的版本 |

**事件篩選**：營收年增率 < -10% 的公告 {f_all} 筆 → T0 有收盤價、T1 有成交 {f_ok} 筆 → T1 開盤跳空 ≤ -5% **{f_final} 筆**。

## 三、研究方法

| 項目 | 設定 |
|---|---|
| 進場 | T1 開盤買進；開盤漲停或沒有成交延後一天，隔天仍買不到就放棄 |
| 日內 | T1 收盤賣出；收盤跌停或沒有成交就延到下一個交易日收盤（同一天進出適用當沖稅率） |
| T+1 | T2 開盤賣出；開盤跌停或沒有成交就延到下一個交易日開盤 |
| 資金 | 本金 100 萬元。每檔上限 = 前一天收盤總資產 ÷ 平均一天持有檔數（只算有部位的日子）；有新股票進場的那天，所有部位調整到 min(上限, 1 ÷ 持有檔數)，現金不夠時新股票平分剩下的現金，不放棄訊號（連一股都買不起才放棄）；買賣都無條件捨去到整數股；同一檔同時只持有一筆 |
| 成本 | 手續費 0.1425% × 3 折（買賣各一次）；證交稅 0.3%，當沖 0.15%；滑價買賣各一個升降單位（不超過漲跌停價） |
| 指標 | 夏普值 = 年化報酬 ÷ 年化波動；索提諾比率 = 年化報酬 ÷ 年化下檔波動；無風險利率 0 |
| 基準 | 0050：本金 100 萬元在第一個訊號日的隔天開盤以整數股買進，股息再投入 |

- 接近跌停開的股票常常收盤也跌停，賣不掉要延後，平均反而虧損。
- 營收衰退越大，反彈越明顯，但這組的成交張數也越少，要和流動性一起看。

### 3. 訊號集中在少數幾天

營收大多在每月 10 日前後公布，同一天常有十幾個訊號，這時每檔分到的金額變小；訊號少的日子每檔最多投入總資產的 {日內｜全部_cap}。

## 五、結論

1. **日內只小賺，遠輸 0050**：總報酬 {日內｜全部_ret}、年化 {日內｜全部_cagr}、夏普值 {日內｜全部_sharpe}；0050 同期 {b_ret}、夏普值 {b_sharpe}。
2. **T+1 虧損**：總報酬 {T+1｜全部_ret}、夏普值 {T+1｜全部_sharpe}。
3. **獲利只出現在冷門股**：實際很難用開盤價買到足夠的量。

**限制**：

1. **開低條件要開盤後才知道**：跳空 ≤ -5% 要等 T1 開盤才確定，回測假設能用開盤價（加一個升降單位）買到，實際上會買在開盤之後的價格。
2. **冷門股的成交價**：均額不到 1 千萬的股票 T1 平均只成交 {g_a200[3]} 張，開盤價常是零星成交，實際的買賣價差和衝擊成本可能比一個升降單位大很多。
3. **資金分配**：每檔上限依整段期間的平均持有檔數決定（用到全期資訊）；同一天訊號很多時每檔金額變小，結果對資金規則很敏感（依代號順序買進、放棄現金不夠的訊號時，日內｜全部約 +50%）。
4. **公告時間**：資料只有公告日、沒有時間；如果公告在盤前或盤中，部分資訊在 T0 就已經反映。
