# 跳空與隔夜報酬

> **先講結論**：跳空的大小對隔夜報酬（跳空當天收盤買、隔天開盤賣）影響很小。只要跳空當天沒收在漲跌停，不論往上或往下跳多少，隔夜平均都在 +0.2%～+0.5%，和沒跳空的日子（+0.25%）差不多。真正拉開差距的是收盤有沒有鎖在漲跌停：收漲停的隔夜 +2%～+4%，但通常買不到；收跌停的多半繼續跌。跳空越大，當天盤中反轉越多；往下跳時，跳空當天量縮的隔夜比爆量的好。

資料期間：{start} ～ {end}

## 一、研究目的

1. 跳空的大小（幾倍標準差）和當天收盤買、隔天開盤賣的**隔夜報酬**有沒有關係？
2. 跳空當天盤中會不會反轉？
3. 開在前一天 K 棒之外的跳空，之後會不會回到前一天的 K 棒？
4. 跳空當天的成交量，能不能分出隔夜報酬的好壞？

## 二、資料處理

| 項目 | 處理方式 |

| 範圍 | 上市櫃普通股（含已下市櫃的股票） |

| 流動性 | 跳空前一天為止的 20 日平均成交量超過 500 張 |
| 價格 | 報酬用還原股價（含除權息） |

| 排除 | 判斷方式 |
|---|---|
| 資料有誤 | 5314 的價格資料有誤，整檔排除 |
| 暫停交易 | 跳空前 20 天到隔天之間有一天沒成交或沒資料，或前一天到隔天在暫停交易期間內 |

| 全市場極端日 | 0050 跳空或前一天漲跌超過自己標準差的 4 倍，或跳空超過 ±5%（共 26 天） |

## 三、研究方法

| 項目 | 定義 |
|---|---|
| 跳空 | 當天開盤 ÷ 前一天收盤 − 1 |
| 跳空倍數 | 跳空 ÷ 到前一天為止 20 日日報酬的標準差；-0.1～0.1 倍當作「沒跳空」的對照組 |
| 盤中 | 跳空當天收盤 ÷ 開盤 − 1 |
| **隔夜** | **隔天開盤 ÷ 跳空當天收盤 − 1** |
| 開在 K 棒外 | 往上跳開在前一天最高價之上；往下跳開在前一天最低價之下 |
| 開在 K 棒內（實體外） | 開在前一天最高、最低價之間，但在實體之外 |
| 量比 | 跳空當天成交量 ÷ 前 20 日平均成交量 |

報酬都未扣成本，買賣一次的成本約 0.39%。個股的隔夜報酬本來就偏正，所以要和「沒跳空」的組比，不是和 0 比。

### 6. 跳空當天的成交量

跳空越大量比本來就越高，所以**在每個跳空倍數組內，把量比分成三等分**：量縮、中等、爆量。全天成交量要到收盤才確定，但收盤前已大致知道，可以用來決定收盤要不要買。

![跳空當天成交量與隔夜報酬（排除收漲跌停）](vol_ov.png)

- **往下跳：量縮的隔夜最好，爆量的最差**。-3～-2 倍量縮 +0.74%（勝率 65%）、爆量 +0.17%（勝率 47%）；3 倍以上量縮 +0.43%、爆量 -0.22%。2016～2019 年各組都接近 0，2020 年以後才明顯。
- **往上跳：影響不大**，三組都在 +0.16%～+0.38%，沒有一致的方向。

![跳空當天成交量與回到實體 K 棒內的比例（開在 K 棒外、當天）](vol_fill.png)

- **爆量的比較不容易回到實體內**：往上跳 1～1.5 倍，當天量縮 58%、爆量 35%；往下跳 -2～-1.5 倍，33% 對 22%。

## 五、結論

1. **跳空大小對隔夜報酬影響很小**：沒收漲跌停時，隔夜平均都在 +0.2%～+0.5%，和沒跳空的 +0.25% 差不多，多半不到買賣一次的成本（約 0.39%）。
2. **跳空的影響主要在當天盤中**：跳得越大，盤中反轉越多。
3. **真正決定隔夜報酬的是收盤有沒有鎖在漲跌停**：收漲停隔夜 +2%～+4%，但很難買到；收跌停多半繼續跌。
4. **開在前一天 K 棒外的比較不容易回去**，跳空越大越難；當天守住的隔夜比較好，全部來自收漲停。
5. **往下跳要看成交量**：量縮的隔夜比爆量好，2020 年以後才明顯；爆量的跳空比較不容易回補。

**限制**

- 報酬未扣成本，也沒考慮能不能用收盤價買到、開盤價賣到。
- 全市場極端日、連續漲跌停的門檻是自己訂的，量比三等分的門檻用了全期資料。
- 同一天很多股票的結果彼此相關，筆數會高估結果的可靠程度。
- 這是統計研究，不是回測：沒有模擬資金分配，也沒有和 0050 買進持有比較累積報酬。
